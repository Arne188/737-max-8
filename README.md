# TUI Boeing 737 MAX 8 – LEGO MOC

Digitales Konstruktionsprojekt im Maßstab ca. 1:50. Ziel: ein erkennbares, später baubares Modell aus echten LEGO-Teilen mit TUI-Sonderlackierung.

## Live-Ansicht
Nach Aktivierung von GitHub Pages: https://arne188.github.io/737-max-8/

Der aktuelle mobile 3D-Viewer zeigt **eine Formreferenz, kein geprüftes LEGO-Modell**. Die zukünftige LEGO-Ansicht soll direkt aus den LDraw/Studio-Daten entstehen.

## Ordner
- `docs/`: mobilfähiger Webviewer (GitHub Pages)
- `models/`: spätere Studio-/LDraw-Konstruktionen
- `plans/`: Aufgaben und Freigabekriterien
- `.github/workflows/`: Veröffentlichung nur bei Änderungen am Viewer

## Konstruktionsregeln
Keine fiktiven LEGO-Teile; keine unbelegten Behauptungen über Baubarkeit. Teilnummern, Verbindungspunkte, Kollisionen und Stabilität sind vor einer Einkaufsliste zu prüfen.

Zielabmessungen: ca. 79 cm Länge, 72 cm Spannweite, 7.5 cm Rumpfdurchmesser. Die Maße sind Entwurfsziele, keine fertige Bauteilprüfung.
